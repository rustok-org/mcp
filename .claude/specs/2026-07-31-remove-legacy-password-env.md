## Что реально чиним

1. **Credential Access (High, 70%)** — убрать абзац-признание «Legacy: inline `-e` password /
   `--env-file`. Both still work but are deprecated» из `SKILL.md`. Ничего в коде не убирается
   (и не может быть убрано — `podman secret type=env` физически неотличим от bare `-e` изнутри
   контейнера). Убираем только формулировку, которая описывает это как «открытую дыру», а не
   объясняет, что рекомендованный способ уже безопасен. Ровно тот паттерн, что уже на
   консольной линии — там этого абзаца никогда не было.
2. **Description-Behavior Mismatch (Medium, 94%)** — шапка `SKILL.md` (frontmatter `description`
   + первый абзац тела) говорит «MCP over stdio» без оговорок; добавить честную строку про
   `POST /api/v1/wallet/sign_typed_data` — loopback-only HTTP-гейтвей для интеграций
   (проверено: биндится на `127.0.0.1`, `Dockerfile.wallet` без `EXPOSE`, наружу не торчит).
