# Rustok MCP Server

Rustok MCP Server is a Python adapter between MCP clients and the Rustok
Gateway. It provides stdio and SSE transports. Wallet cryptography, signing
and key storage belong to Rustok Core.

The `rustok-mcp` command starts the network server. The `rustok-mcp-stdio`
command starts the stdio adapter. Configuration uses environment variables.

For wallet installation, capabilities and maintenance, use the documentation
and signed assets for the selected wallet release:
[Rustok MCP repository](https://github.com/rustok-org/mcp) and
[wallet releases](https://github.com/rustok-org/mcp/releases).
